# Paz

Experimental AUR helper written in zig

## Basic usage 

`paz -Syu` -- Run full system upgrade.

`paz` -- Alias for `paz -Syu`.

`paz -S <target>` -- Install a specific package.

`paz -R <target>` -- Uninstall a specific package.

`paz -Qs <keyword>` -- Search installed package.

`paz -h` -- Help menu.
